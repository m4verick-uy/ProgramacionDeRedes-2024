# Práctico 1

### Ejercicio 1)

Desarrolle un programa que tenga 2 hilos de ejecución, uno que imprima 20 ‘x’, y el otro que
imprima 20 ‘y’, entre la impresión de cada carácter haga una espera de 100 mseg. Logre que
primero se impriman todas las ‘x’. Haga esto de al menos 2 formas distintas.

### Soluciones

- **Primera Forma:** Uso de `Thread` y `Join`.
- **Segunda Forma:** Uso de `Thread` y `AutoResetEvent` para sincronización.
